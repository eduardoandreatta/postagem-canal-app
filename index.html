Postagem Canal Eduardo

Ferramenta pessoal de publicação de vídeos. Ela usa a API do YouTube (YouTube Data API v3) para enviar vídeos aos canais do próprio dono do aplicativo, com título, descrição e agendamento, sem precisar abrir o YouTube Studio.

O aplicativo não é um serviço público: ele só é usado por contas autorizadas pelo desenvolvedor, para publicar nos canais dessas mesmas contas.

Política de Privacidade

English

Personal video publishing tool. It uses the YouTube Data API v3 to upload videos to channels owned by the app owner's own authorized accounts. It is not a public service. See the Privacy Policy.
