Política de Privacidade

Aplicativo: Postagem Canal Eduardo. Última atualização: 18/11/2026.

O que o aplicativo acessa

Quando uma conta Google autoriza o aplicativo, ele recebe permissão para (1) enviar e gerenciar vídeos no canal do YouTube dessa conta e (2) ler informações básicas desse canal (nome, identificador e estatísticas públicas), para confirmar em qual canal vai publicar.

Como os dados são usados

Os dados do YouTube são usados somente para publicar os vídeos que o próprio dono da conta escolheu publicar. Não vendemos, não compartilhamos, não transferimos e não usamos esses dados para publicidade ou para treinar modelos.

Onde os dados ficam

A chave de acesso (token) fica guardada apenas no computador de quem opera o aplicativo e não é enviada a terceiros. Nenhum dado de espectadores é coletado.

Como revogar o acesso

A qualquer momento a conta pode remover o acesso em myaccount.google.com/permissions. Os dados guardados localmente podem ser apagados a pedido, removendo o token.

Serviços do YouTube

O aplicativo usa os Serviços de API do YouTube. Ao usá-lo, vale também os Termos de Serviço do YouTube e a Política de Privacidade do Google.

English

This app uses the YouTube API Services. With the account owner's authorization it uploads videos to that account's own YouTube channel and reads basic channel information (name, ID, public statistics). Data is used only to publish videos the account owner chose to publish; it is not sold, shared, transferred, or used for advertising or model training. The access token is stored only on the operator's own computer. Access can be revoked at any time at myaccount.google.com/permissions. See also the YouTube Terms of Service and the Google Privacy Policy.
